### 2. 커밋 메시지 및 Merge Request(MR) 규칙

#### 커밋 메시지 구조

```
접두사 라벨: [지라번호] 지라제목
-> (수정내용작성) 상세내용
```

**예시**

```
feat: [BTOCSITE-70849] 고객지원 > 예약조회/변경 > 제품 및 설치환경 사진 등록 변경요청
-> (수정내용작성) 사진등록 수정
```

#### 허용 커밋 접두사 라벨

| 접두사 | 용도 |
|--------|------|
| `feat` | 새로운 기능 |
| `fix` | 버그 수정 |
| `design` | 디자인 |
| `style` | 코드 변경(포맷 등) |
| `refactor` | 코드 리팩토링 |
| `comment` | 주석 추가 |
| `docs` | 문구 수정 |
| `test` | 테스트 코드 |
| `chore` | 빌드 업무 수정 |
| `fixes` | 이슈 수정 |
| `resolves` | 이슈 해결 |
| `ref` | 참고 이슈 |
| `related to` | 관련 이슈 번호 |

#### MR 제목 규칙

| 유형 | 형식 |
|------|------|
| 일반 | `[셀명][지라번호] 지라제목` |
| 긴급/비정기 | `[긴급/비정기][셀명][지라번호] 지라제목` |

| 산출물 | 작성 요령 |

#### [4단계] MASTER(운영) 배포 요청

| 항목 | 설정값 |
|------|--------|
| MR 대상 | `master` 브랜치 |
| MR 본문 | STG와 **동일 템플릿** 사용 |
| **Assignee** | 변주현 책임님, 김영욱 수석님 |
| **라벨 (7개 필수)** | `Type::CSR`, `Deploy: 최초배포`, `Deploy DD:: dd`, `Deploy MM:: mm`, `priority: 정기`, `QA: skip`, `Cell::<cell-support>` |
| **옵션** | `Delete source branch when merge request is accepted.` **반드시 체크** |
| **배포시트** | 노션 자동 연동 여부 확인 |

## 빠른 참조 — 전체 워크플로우 한눈에

```
[Git] CSR(BTOCSITE-) → 브랜치 생성 → DEV 검수 → STG MR → CST 공유
  → 산출물 작성 → MASTER MR → Standby/Active 검수 → 운영 확인

[CMS] 로컬 temp 검증 → 운영 CMS 등록 → 이미지 업로드/Approve
  → 도메인 제거 → STG 미리보기 → CST 검수 → Jira 완료

[BCS] lgekor-ui-master 로컬 작업 → ~inner.html 검증
  → CCProfessional 햄버거 복붙 → publish/Approve
  → 운영 CSS/JS 다운로드 → edit 반영 → gulp static:kr
```
